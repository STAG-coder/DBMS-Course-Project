# Presentation III UI

## Setup
1. Install Python 3.
2. Install dependency: `pip install -r requirements.txt`
3. Run `smart_parking_final.sql` in MySQL.
4. Open `app.py` and set `DB_CONFIG["password"]`.
5. Run `python app.py`.

## Live demo
- Insert: enter vehicle data -> Add Vehicle.
- View: View / Refresh.
- Delete: select a row -> Delete Selected.
- Take screenshots before and after each operation.

The UI intentionally focuses on Vehicle CRUD so the three required operations are easy to demonstrate live.
